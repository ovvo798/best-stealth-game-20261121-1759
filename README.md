Night Shift: The Gallery Heist — an original top-down 2D stealth game. Sneak through three museum wings, steal every artifact, and reach the exit unseen. Guards patrol learnable routes with vision cones, suspicion builds in the light and decays in cover, and running is loud. Shift to sneak, watch the cones, and slip out before the alarm catches you.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser and play with keyboard and mouse.
